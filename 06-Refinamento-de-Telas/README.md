# 06 - Refinamento de Telas

Levantamento inicial das telas do app "Eu Duvido!", derivado dos requisitos ([07](../01-Definicao-do-Sistema/07-Requisitos.md)), regras de negócio ([08](../01-Definicao-do-Sistema/08-Regras-de-Negocio.md)) e do schema ([12](../03-Implementacao-e-Desenvolvimento/12-Banco-de-Dados.md)). Cada arquivo é uma tela: objetivo, seções principais, dados de origem, decisões já validadas com o time e TODOs em aberto.

Rascunho para validação com o time — as dúvidas respondidas no PR já estão em "Decisões" em cada arquivo; o que ainda está em "TODOs" segue pendente (em geral, ajustes no schema para acompanhar as decisões).
