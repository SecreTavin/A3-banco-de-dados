# AAAA-MM-DD — Título curto da alteração

| Campo | Valor |
| --- | --- |
| **Data** | AAAA-MM-DD |
| **Responsável** | Nome de quem conduziu e validou |
| **Ferramenta** | Ex.: Claude Code (Opus), GitHub Copilot, ChatGPT |
| **Artefato afetado** | Arquivos, tabelas ou documentos alterados |

## O que foi pedido

Descrição do objetivo em uma ou duas frases. Se o prompt foi relevante, cite-o
ou resuma o que foi solicitado.

## O que a IA produziu

O que veio pronto e foi aproveitado.

## O que a IA errou

**Seção mais importante do registro.** O que veio incorreto, incompleto ou
inadequado ao contexto do projeto. Se não houve erro, escreva "nenhum erro
identificado" — mas confira antes, porque essa é a exceção, não a regra.

## Como o time validou

Como a saída foi verificada: execução do script, teste que passou, revisão em
PR, conferência contra a documentação. Validação precisa ser algo que aconteceu,
não uma afirmação de que "foi revisado".

## Decisão final

O que entrou no repositório, com qual ajuste.
