# 02 - Introdução

O projeto **Eu Duvido!** formaliza e gamifica apostas e desafios informais através de um software centralizado sobre um Banco de Dados relacional, permitindo a criação de grupos de amigos, registro formal de desafios (com recompensas financeiras ou prendas), submissão de fotos/vídeos comprobatórios e sistema de júri por votação democrática.
